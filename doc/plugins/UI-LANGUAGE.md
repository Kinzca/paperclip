# 双语界面维护说明

## 用户入口与保存范围

公司切换菜单底部及 设置 → 个人资料 中提供“语言／Language”，支持简体中文和 English。用户选择保存在当前浏览器、当前站点的 localStorage（`paperclip.ui.locale`），不改变公司的语言或业务设置；本机信任模式的同源标签页共享该选择。不同浏览器、设备和站点地址不自动同步。此实现不是账号服务端偏好；同一浏览器配置内切换登录账号也沿用浏览器选择。

没有保存记录时，浏览器语言以 zh 开头则使用简体中文，否则使用 English。存储不可用时仍允许当前会话切换，并显示未保存提示。

## 文案与内容边界

只把明确的固定 UI 文案接入 `uiText`，从源代码层区分界面和用户内容。没有在 DOM 上扫描替换文字。

- 翻译：固定导航、按钮、字段、筛选、提示、状态与流程阶段显示。
- 原样保留：任务标题、任务正文与评论、代码、Agent 名称、用户填写的职位、组织与项目名称、Wiki 页面标题和正文、原始审查报告、后台错误原文。
- 状态码和角色码不修改；标准角色的 UI 标签使用只读按需译文，用户填写的名称和标题不走该路径。
- Office 中的阶段文字来自已存在的阶段值，仅翻译显示文字，不改阶段判断、轮询周期或画布循环。

优先覆盖主侧栏、任务和 Agent 常用操作、个人／公司／实例／插件设置，以及两个插件的常用界面。第三方和未接入的次级界面可能仍有英文；这不是整站任意内容的自动翻译。

## 宿主资源

`ui/src/i18n/ui.ts` 复用现有 i18next 语言状态，并为固定 UI 提供扁平资源。JSON 文件位于 `ui/src/i18n/messages/`，与仅覆盖初始建公司的旧 app 命名空间分离，避免破坏其他已有语言文件的契约。

```tsx
import { uiText, useUiLocale } from "@/i18n/ui";

export function Example() {
  useUiLocale();
  return <button>{uiText("Save")}</button>;
}
```

固定模板使用 `{{value0}}` 等显式参数。宿主先取译文，再只插入明确提供的参数；不会递归解析用户值或修改示例代码中的 `{{ agent.name }}` 标记。React 负责按文字渲染，不使用 HTML 注入。

不要把任务、评论、名称等自由文本直接传给 uiText。已有固定 UI 文案没有译文时使用原文／英文回退，后续应显式补充资源。

## 插件接口

配套 Fork SDK 的 `@paperclipai/plugin-sdk/ui` 提供：

```tsx
import { useHostLocale, translateUi } from "@paperclipai/plugin-sdk/ui";

export function PluginButton() {
  useHostLocale();
  return <button>{translateUi("Save")}</button>;
}
```

新文案也要添加到宿主资源中。当前接口让已适配插件跟随宿主，不自动翻译其他第三方插件。Office 0.4.0 / Wiki 0.1.2 需要此宿主前端桥，不能单独升级到尚未提供这两个导出的旧宿主。

## 发布与本轮状态

构建宿主、SDK 和两个插件，部署宿主 UI 后通过原生 upgrade 接口升级插件，沿用安装 ID 和公司配置。源代码及安装脚本固定的 Office 提交均已更新。Wiki 初始化目录和维护员、计划状态不重置，不自动导入资料。

按用户要求，没有运行测试、单独类型检查、代码审查、设计检测或浏览器／任务验收。语言持久化、同源标签同步、不同屏幕宽度、完整交互与原文保留等都交由用户检查；构建结果不替代验收。
