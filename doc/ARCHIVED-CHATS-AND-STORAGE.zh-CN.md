# 已归档对话与存储空间

设置侧栏提供「已归档的对话」「存储空间」和独立的「公司与项目空间」，使用宿主的布局、按钮、选择器、确认弹窗及语义令牌，支持简体中文与英文。存储总览另有公司与项目空间的管理入口；分类使用独立彩色令牌，图例固定单行，窄屏可横向滚动。

## 已归档的对话

按当前组织、当前用户显示仍处于归档状态的任务对话，支持按标题/任务编号搜索、项目筛选、分页加载和取消归档。取消归档只恢复收件箱可见性，不恢复暂停的任务或启动员工。

永久删除需要单独确认，删除的是整个任务记录及其评论、文档、附件，对所有协作者生效，同时清理已确认的独占文件；共享项目原件和保留项不删除。未完成、含子任务、有排队/运行记录，或存在未结束（包括暂停）工作流的任务不能从这里删除。其他记录的外键引用仍可能阻止删除，界面会保留具体错误。支持预览后确认批量删除，但不自动清理。

接口：

- `GET /api/companies/:companyId/archived-chats`：仅 board 用户；沿用公司访问及任务读取策略。参数 `q`（最多 200 字符）、`projectId`（UUID 或 `none`）、`limit`（1–100，默认 50）、`offset`。返回带 `archivedAt` 的任务数组，包含普通任务与员工对话，不采用普通列表中排除对话的默认过滤。
- `DELETE /api/issues/:id?archivedChat=true`：沿用任务删除接口、附件清理和审计；事务内锁定任务并检查当前用户的有效归档、任务状态、子任务和执行状态。普通删除接口行为不变。
- `DELETE /api/issues/:id/inbox-archive`：复用取消归档接口，不提交任务恢复动作。

## 存储空间

`GET /api/instance/storage` 仅实例管理员（或本机可信操作员）可读。显示当前实例目录、配置的本地数据库、日志、文件存储、备份、托管工作区，以及所有公司已登记的本地项目目录的文件逻辑大小；不是整个开发目录、所有安装发布包、磁盘剩余空间或可回收空间。

扫描仅使用文件元数据，不读取文件内容、不计算摘要、不跟随符号链接；对重叠目录只计一次。普通统计最多扫描 200,000 个目录项，时间预算 3 秒，结果缓存 30 秒并合并同时到来的请求。文件消失可跳过；路径不可读或达到上限时返回 `complete: false`，页面标明「至少已占用」与部分统计。扫描不是一致性快照，原地增长的日志可能继续变化。

已登记的外部工程目录计入「公司与项目目录」，嵌套、重复及与实例重叠的路径只统计一次。远程数据库、S3、未登记目录及链接目标不计入。普通统计上限为 20 万项、3 秒；可只读扩大至 50 万项、10 秒。两种结果分别缓存 30 秒，未完整统计明确标为下限。设置侧栏「公司与项目空间」位于「已归档的对话」上方。此页面不提供数据库、备份或源码删除；管理入口连接已归档对话和现有工作区页面，不新增自动工作树保留策略。

物理清理使用 0338 新增的 `archive_cleanup_jobs` 表；只增加清理台账，不改写既有业务记录、员工配置或工作流状态。

## 批量清理与空间估算

归档页可选择已加载的记录（最多 200 条），从「批量删除所选记录」进入预览；「自动排除关联任务」位于操作栏右侧，不另设说明行或预览全部筛选结果入口。`POST /api/companies/:companyId/archived-chats/cleanup-preview` 只读：接收 `issueIds` 或 `filters`，沿用 board、公司、任务读取及用户归档范围检查，返回候选/保护等级与原因。不可用记录不返回标题或编号。

选择阶段使用 `includeFiles: false` 只检查可清理条件，不扫描文件。全选仅选择可清理记录，受保护项不可勾选；切换关联任务过滤会重新检查并移除不符合条件的已选项。预览不解除暂停、不更新状态、不删除记录。默认勾选「自动排除关联任务」：排除父任务链接、双向依赖和任务引用；含子任务、未完成、排队/运行及未结束工作流始终受保护。取消该选项不会解除这些基础保护。

`POST /api/companies/:companyId/archived-chats/cleanup` 必须提交明确的 `issueIds`（最多 200 条）、`skipRelated` 以及 `confirm: true`，不接受筛选器直接删除。仅 board，验证公司和任务读取范围、当前用户有效归档。按记录独立事务锁定任务并重新检查状态及关联，重复 ID 去重；状态改变或外键引用导致的冲突跳过，并逐条返回删除/跳过/失败及原因。已删除记录不重复处理。每条成功删除写入审计。附件清理失败明确提示，不计入已清理附件大小；未知数据库错误使当前记录回滚并报告失败，不掩盖错误。

单条与批量预览列出文件路径和逻辑大小，分别显示本地文件预计回收量与任务/评论数据库记录估算。摘要和按钮固定，中部一个滚动区；默认展示候选记录，排除项折叠。不再提供「预览全部筛选结果」入口，过滤选项位于操作栏右侧。

物理文件范围：

- 本地独占附件：按登记的对象键识别，检查存储根目录、公司前缀、符号链接和文件身份（设备、inode、大小、修改时间），不计算文件摘要。
- 已结束运行日志：仅接受该任务直接拥有的运行、标准公司/员工/运行 ID 路径，拒绝共享引用和仍执行中的运行。清理本地日志后清除对应日志定位；云端日志镜像和未登记临时文件保留。
- 独占 Git 工作副本：必须已关闭、由运行时创建、没有其他任务或运行使用、不与登记项目目录重叠，且成果已合入基线，无修改、未跟踪或忽略文件。通过现有生命周期锁和代际检查后，只执行不带 force 的 Git worktree remove，不运行用户清理命令、不删分支、不触碰项目源码或实例数据库。
- 共享项目源码、资产、交付物、备份、未登记临时内容和无法确认归属的文件保留，并显示原因。项目空间页面仍只读。

任务删除与物理清理台账在同一事务中提交，台账不以外键依赖被删除的任务；文件删除在提交后进行。每个文件独立报告状态。清理失败或进程中断不会丢失清单，用户可从「未完成的文件清理」查看并确认重试。重试按公司和当前用户授权，锁定台账防止并发重复执行；文件被替换、工作区重新启用或出现共享引用时保留，不擅自更新清理范围。删除及重试写入审计。

`GET /api/companies/:companyId/archived-chats/pending-cleanup` 返回当前用户未完成的清理台账；`POST .../pending-cleanup/:jobId/retry` 只重试台账里的文件，不接受客户端文件路径。成功清理过的文件不重复计数。

空间统计采用文件元数据；远程对象、项目原件、整库备份和数据库索引不计作本地可回收量。数据库删除通常供内部复用，不承诺磁盘文件即时缩小。

## 公司与项目空间（仅预览）

`GET /api/companies/:companyId/project-space` 仅实例管理员或本机可信操作员可读，并检查公司访问与项目读取范围。目录来自项目工作区和本地执行工作区的已登记绝对路径，不接受任意扫描路径。不跟随链接、不读取文件内容、不计算摘要。缺失、不可读及超预算的目录明确标记，不当作完整零占用。

按公司 → 项目 → 已登记根目录 → 顶层目录分类展示；源码/原始资产、交付物、构建产物、依赖、缓存、临时及未分类分别列出。相同及嵌套路径在项目内去重；与其他项目或公司重叠的路径单列共享占用，公司共享总量取目录并集，不与各项目重复相加。局部或缺失扫描会使公司统计成为下限。

保护等级：

- 受保护：源码、原始资产、交付物、未分类内容、共享路径，以及有未完成/暂停流程或未关闭执行工作区的项目。
- 待确认可重建：无上述保护条件时，按名称识别的构建、依赖、缓存和临时目录。仅是分类提示，不代表可删除，尚需确认项目规范、可重建方式和引用。
- 可清理候选：须另行验证临时资源归属及无引用。本轮不自动把目录提升为此等级，没有文件清理接口。

单根目录预算为 30,000 项/2 秒，一次公司扫描预算为 6 秒；未完成部分显示下限。附件与日志是登记元数据，独立展示且不计入本地工程目录总量；不能归属可见项目的登记值另列。数据库和整库备份保留在实例总览，不摊入项目。

达到快速扫描上限后，可以手动选择「扩大统计范围（只读）」：`?scan=expanded` 将单根预算扩大为 300,000 项/6 秒，公司预算 20 秒，不改变默认扫描。仍未完成的子目录标为「未完整统计」或占用下限，不显示为确定的零占用。
# 父子对话归档

在收件箱开启 parent-child 模式后，归档父对话会在同一事务中归档该对话及当前用户可见、已结束（done/cancelled）的全部子孙对话，不受当前列表是否已加载这些子项影响。未结束的子任务保留可见，提示显示保留数量；操作不会暂停、取消任务或删除文件。

完成提示提供“撤销整组归档”，键盘撤销也针对同一批记录。撤销只恢复本次归档的记录，此前已经归档的记录不受影响；之后又被单独归档的记录也不恢复。撤销回执只在当前页面会话中保留，刷新后可在“已归档对话”中逐条恢复。关闭 parent-child 后，原有单条归档方式保持不变。所有操作继续遵守公司、用户及可见性边界，不修改历史归档记录。
