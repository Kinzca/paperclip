# 统一本地发布流程

## 范围

以主线提交和清单固定宿主后端、UI、SDK、Office 与 Wiki。提供新装、旧实例接管、离线备份与迁移、版本切换、兼容代码回退。复用原数据和登录，不同步业务配置，不启动 Agent 验收。

## 交付约定

- 使用 Node.js 24.22.2、pnpm 9.15.4、已提交锁文件与固定 Office 提交。
- 核心源码、adapter-utils 和服务使用的适配器重新编译；runner、原生程序和 CLI 使用锁定发布依赖，在清单中区分来源。
- 成功发布目录不可覆盖，运行选择使用原子指针；升级失败保留检查点与待完成记录。
- SQL 或插件迁移不兼容时拒绝代码降级，完整数据恢复使用独立实例。
- 新装与跨电脑迁移不继承本机业务名称、路径或授权；说明文档更新旧默认额度至 5 / 180 / 2。

## 交付证据边界

执行部署工具的隔离单元检查和必要构建；本机停止服务、接管、备份、升级、启动属于部署操作。最终记录实际提交、迁移结果和健康状态。页面、真实 Agent 工作流、新电脑安装及备份恢复不作为本轮已通过结论，由用户检查。
